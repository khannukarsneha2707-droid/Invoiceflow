# **App Name**: InvoiceFlow

## Core Features:

- User Authentication: Secure user registration and login functionality using email and password, powered by Firebase Authentication.
- Dashboard Overview: A personalized dashboard presenting a clear overview of invoice statuses and key metrics upon login.
- Invoice Creation: A streamlined form to create new invoices, capturing essential details like client name, email, amount, status, and date. Data is stored in Firestore.
- Invoice Management: Functionality to edit and delete existing invoices from the database, ensuring accurate record-keeping in Firestore.
- Invoice Listing: A sortable and filterable list view of all created invoices displayed prominently on the dashboard.
- AI Invoice Content Tool: A generative AI tool that suggests professional invoice item descriptions or standard payment terms to accelerate invoice creation.

## Style Guidelines:

- Primary interactive elements color: A sophisticated, muted blue for trust and professionalism (#3960AC).
- Background color: A subtle, desaturated off-white with a hint of blue, promoting a clean and focused workspace (#F0F2F4).
- Accent color: A vibrant cyan-blue for call-to-actions and highlights, providing clear visual guidance (#3CC2DD).
- Universal font: 'Inter' (sans-serif) for all text, ensuring high readability and a modern, objective feel suitable for a data-rich UI.
- Crisp, minimalist line icons for intuitive navigation and data representation, similar to modern SaaS interfaces.
- Clean, spacious layout with ample white space, prioritizing data clarity and ease of use on both desktop and mobile devices. Sidebar navigation on larger screens.
- Subtle, fluid transitions and micro-animations for interactions like button clicks, form submissions, and data updates, enhancing user experience without distraction.
